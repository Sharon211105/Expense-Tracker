# Expense-Tracker

## Project Overview

Expense Tracker is a web-based application developed using JSP, Servlets, Java, and MySQL to help users manage their daily expenses efficiently. The system allows users to register, log in securely, add, edit, and delete expenses, set category-wise budgets, track monthly savings, receive budget alerts, and generate visual reports using charts.

This project is designed to provide users with a simple and user-friendly platform for better financial planning and expense monitoring.

↓

↓
DAO Classes (Database Operations)

MySQL Database

---

## Database Tables

### Users Table

Stores user registration and login details.

### Categories Table

Stores budget categories and budget limits.

### Expenses Table

Stores all user expenses with title, amount, date, and category.
